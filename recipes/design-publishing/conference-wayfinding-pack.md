# Conference Wayfinding Pack

Build a consistent conference sign system that distinguishes event navigation from official safety signage.

## Scenario

A small technical conference uses several rooms in an unfamiliar building. Attendees need help finding registration, talks, and refreshments, including an approved step-free route. You have a venue plan but no sign system, and you must avoid contradicting the building’s official safety signage.

## Inputs to prepare

- A venue-approved floor plan and room-name list
- Approved event destinations, session labels, and sign placement points
- Venue-confirmed accessible routes and off-limits areas
- Print sizes, mounting constraints, brand guidance, and review owner

## Copy this prompt into dot

```text
dot, prepare a wayfinding pack for [EVENT] using [VENUE-APPROVED PLAN], [ROOM LIST], and [APPROVED SIGN LOCATIONS]. The pack should help people find [EVENT DESTINATIONS]. Begin with a route-and-sign inventory; ask the venue owner to resolve any unclear entrance, floor transition, or accessible route. Do not infer accessibility, emergency exits, occupancy limits, or safe routes from a sketch.

Design a consistent system for entrance welcome, registration, room identification, directional arrows, and a simple event map. Use plain words, high-contrast text, and labels that match the supplied room list exactly. Keep official emergency and building safety signage outside this design scope and never cover, imitate, or contradict it. Mark every arrow with its intended placement and facing direction so a correct design cannot silently become a wrong instruction when installed.

Deliver editable sign masters or a complete specification, a placement schedule, print candidates if supported, and an installation walk-through checklist. Test routes from two approved entrances, a room with a long name, an unavailable corridor, and the venue-confirmed step-free path. Flag any unverified placement or route as blocked for release. Keep venue details within [AUTHORIZED AUDIENCE], and do not publish maps, order prints, or authorize installation without the venue owner’s approval.
```

## Iterate with a purpose

### 1. Walk the routes on paper

```text
Trace each event destination from the two approved entrances and identify missing decision-point signs or contradictory arrows.
```

### 2. Prepare a room change pack

```text
Create a clearly dated replacement-sign plan for [APPROVED ROOM CHANGE], listing which old signs must be removed and which routes need venue reapproval.
```

### 3. Build installation checks

```text
Create a location-by-location installation checklist with facing direction, visibility check, and a field for venue-owner sign-off.
```

## Expected deliverables

- Editable sign masters or design specification
- Route-and-sign placement inventory
- Print candidate pack if supported
- Installation walk-through checklist
- Unverified-route register

## Acceptance checks

- Every room label matches the approved list
- Every arrow has a placement and facing direction
- The venue-confirmed step-free route is checked without invented accessibility claims
- An unavailable corridor is treated as a blocked route
- Long labels remain readable at the intended sign size
- Official safety signage is not replaced or contradicted

## Access, privacy and stop conditions

- Routing accuracy depends on venue-approved information and an on-site check
- The project does not design emergency or safety signage
- Venue maps may be confidential and require a defined audience
- Printing, map publication, and installation require owner approval

## Two possible extensions

- Create a large-print attendee route handout from approved paths
- Develop a reusable room-change checklist for future events
