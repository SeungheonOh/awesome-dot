# Fictional manual packet: PebbleTag L20

This original synthetic manual is a test fixture, not guidance for a real product. All names, versions, page references and behaviors are invented. No external manual was copied or retrieved.

## Request and supplied observations

> Make a checklist for replacing the empty roll in my PebbleTag L20 with the supplied 40 × 25 mm die-cut paper labels. Use this packet only. I have not started replacing it.

The fictional user supplied these observations on 2026-10-01:

- Device label: **PebbleTag L20**, with no “Plus” suffix
- Settings → About: **firmware 2.2**
- Device screen: **Ready**; print queue: **no jobs**
- Settings → Media → Size: **50 × 30 mm**
- New roll package: **40 × 25 mm, die-cut paper labels**
- Current roll is empty

These are user-reported starting observations. They are not a record of anyone carrying out the checklist. Read the normal case using D1 only. D2 is added solely for the separate contradiction case below.

## D1 — User Guide, revision C

Issuer: fictional PebbleTag documentation team. Revision C is dated 2026-08-12. The supplied excerpt contains printed pages 2, 8 and 9, transcribed below with stable clause IDs. Printed page 12 is not supplied. Page 8 states its instructions in text; no omitted illustration is required for this fixture.

### M01

**Printed page 2, “Applies to.”** This guide covers PebbleTag L20 with firmware 2.1 through 2.3. It does not cover PebbleTag L20 Plus or other firmware releases.

### M02

**Printed page 8, “Before replacing an empty roll.”** Use die-cut paper labels in either 40 × 25 mm or 50 × 30 mm. Continuous rolls and film labels are not supported by this procedure.

### M03

**Printed page 8, “Before replacing an empty roll.”** Start only when the display reads Ready and the print queue contains no jobs. If either condition is false, do not start this roll-replacement procedure.

### M04

**Printed page 8, warning before opening the media lid.** Do not press Feed while the media lid is open. Use fingers only for the green release latch. If the latch or holder is stuck, stop; do not force it or use tools.

### M05

**Printed page 8, replacement step 1.** Lift the media lid. Press the green release latch and lift the roll holder. Slide the empty core off the holder.

### M06

**Printed page 8, replacement step 2.** Slide the new roll onto the holder so labels unroll from the bottom toward the front slot, with the label face upward. Seat the holder until it clicks. Pass the leading label through the front slot.

### M07

**Printed page 8, replacement step 3.** Slide the guides to touch the label edges without curling them. Close the media lid until it clicks.

### M08

**Printed page 9, replacement step 4.** Compare the roll package size with Settings → Media → Size. If different, select the exact package size. If already equal, leave the setting unchanged. Confirm the displayed size matches the package before continuing to Feed.

### M09

**Printed page 9, replacement step 5.** With the lid closed, tap Feed once. Proceed to the sample only if one blank label advances to the tear line and the display returns to Ready. Otherwise follow the stop instruction in M11.

### M10

**Printed page 9, replacement step 6.** Choose Tools → Print Sample. Replacement is complete only when the entire sample border fits on one label, with no part missing, and the display returns to Ready. Otherwise follow the stop instruction in M11.

### M11

**Printed page 9, “If the checks fail.”** If the Feed check or sample check fails, stop. Do not press Feed again or change alignment settings. Follow “Align media” on printed page 12 before any further attempt.

## Missing material

“Align media,” printed page 12, is referenced but absent. No recovery steps are available in this packet.

## D2 — Optional contradiction-case input

This source is **not part of the normal case**. Add it when testing the contradiction case in the worked example.

Issuer: fictional PebbleTag documentation team. Title: *L20 Quick Start*, revision Q, dated 2026-09-04. Supplied printed page 1 says it covers L20 firmware 2.1 through 2.3. It contains no correction or supersession statement about User Guide revision C.

### Q01

**Printed page 1, “After changing a roll.”** Once the lid is closed and the selected size matches the roll, press Feed twice before printing a sample, even if the first label is aligned.
