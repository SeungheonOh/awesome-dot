# Evidence source index

These are category guides, not integrations or executable tool declarations. Discover the actual connected tools and schemas in the current host. Read only guides relevant to the scoped question. Use supplied exports when available, with their date and coverage limits.

- [Code archaeology](sources/code-archaeology.md): commits, reviews, tests, and in-repository decisions
- [Issue tracker](sources/issue-tracker.md): user problems, business constraints, parent work, and scope changes
- [Documents](sources/documents.md): accepted designs, alternatives, requirements, and meeting decisions
- [Team chat](sources/team-chat.md): contemporaneous discussions and decisions absent from formal records
- [Observability](sources/observability.md): services, metrics, traces, logs, monitors, and incidents
- [Error history](sources/error-history.md): exception trajectories, release associations, and defensive-code context
- [Analytics warehouse](sources/analytics-warehouse.md): product behavior, experiments, thresholds, and pipeline evidence

[Incident and postmortem context](sources/incident-postmortem.md) is a cross-cutting angle, not an eighth required source. Add it for a plausible defensive or recovery history. Source discovery is not permission to query everything, change integrations, or contact people.
