# Plain-language restatement

Rewrite the last explanation, or the text the user identifies, as one person speaking clearly to another. Replace jargon with ordinary words or a short definition. Lead with the point and keep only the context needed to understand it.

Preserve material uncertainty, prerequisites, risk, attribution, and any decision the user needs to make. Do not add facts, promises, or reassurance. If the original said a test was not run, the simpler version must still say so. Keep exact code, names, amounts, and dates when they matter.

Return the rewritten explanation without narrating the rewrite. If there is no text to restate, ask for it.
