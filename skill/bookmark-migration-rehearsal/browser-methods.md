# Official Browser Methods

Checked on 2026-10-02. Recheck the current article and visible interface for the installed version before acting. These sources establish supported transfer routes, not a guarantee that every metadata field or root placement survives.

- **Chrome desktop:** Google's [import and export guide](https://support.google.com/chrome/answer/96816?hl=en) describes HTML transfer. Export is in Bookmark Manager's menu; import is available under Bookmarks and lists → Import bookmarks and settings. Existing target bookmarks affect where imported entries appear. Record the observed destination instead of assuming the file's outer folder becomes the browser toolbar.
- **Firefox desktop:** Mozilla's [HTML export guide](https://support.mozilla.org/en-US/kb/export-firefox-bookmarks-to-backup-or-transfer) places Export Bookmarks to HTML under the Library's Import and Backup menu. HTML is the cross-browser transfer route; the Firefox-native backup format serves restoration and can replace existing bookmarks.
- **Firefox import:** Mozilla's [HTML import guide](https://support.mozilla.org/en-US/kb/import-bookmarks-html-file) recommends a current-bookmark backup first. Import Bookmarks from HTML adds entries to existing bookmarks and may create duplicates. Its documented destination is the Bookmarks Menu; read back the actual tree in the installed version. Do not use native-backup Restore as an additive migration shortcut.
- **Edge desktop:** Microsoft's [import guide](https://support.microsoft.com/en-us/edge/import-your-favorites-and-passwords-in-microsoft-edge) documents Settings → Profiles → Import browser data, then the HTML favorites/bookmarks option under other import locations. The imported folder may be named Imported. Select the bookmark option; the same article also describes unrelated password transfer, which is outside this workflow.

For another browser, mobile-only flow or managed profile, consult its current official help and inspect available controls. A missing export/import capability is a concrete limitation; it is not permission to copy a browser profile, enable account sync or install an extension. Do not present these route notes as an executed import or a universal UI sequence.
