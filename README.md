# awesome-dot

Workflow skills for dot. Each skill explains the inputs, steps, decision points, outputs and checks needed to complete a specific task.

Give dot a skill's link or contents along with your task and relevant inputs. The instructions and any examples or supporting files live together in that skill's folder.

For example, you can [reconcile planned and actual spending](skill/budget-variance-waterfall/SKILL.md), [turn a vague bug report into a reproducible investigation](skill/bug-reproduction-triage/SKILL.md), or [prepare a change for code review](skill/code-review-handoff/SKILL.md).

The guides distinguish completed work from unverified steps. Available tools, account access and required approvals still determine what can be carried out. Reading a skill does not install it or grant it access.
